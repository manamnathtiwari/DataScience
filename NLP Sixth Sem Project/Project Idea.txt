The project idea is to make an application that can create insightful stories from any form of datasets 

Input Form :
            1. Excel 
            2. CSV
            3. Selection of Story Style 

Inner Processing :
            1. Data Analysis 
            2. EDA Performing 
            3. Data Description using LLMs

OutPut Form :
            1. Story of the data in the form of input Style 
            2. Visualization of the Data Automatically

Motivation for the Project :
    It is very difficult for data enginners to explain the data as it takes time to analyse and understand any data
    This Project aims to develop a tool to quickly analyse the data and give a story based on the style preffered by the user
